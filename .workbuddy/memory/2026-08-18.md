# 2026-08-18 工作日志

## FreeControl 二次开发：UI 高级化（功能逻辑不动）
- 项目背景：基于 scrcpy 的 PC 端 Android 控制工具，C#/WinForms + SunnyUI 3.0.3 + .NET Framework 4.7.2。架构地图已写入 MEMORY.md。
- 用户需求：视觉风格焕新 + 小步调样式（保留布局）+ 尽可能高级 + 功能逻辑完全不动。
- 落地改动（仅 `FreeControl/Main.cs`）：
  - 重写 `UpdateStyle(bool isDark)`：把分散硬编码色收敛为语义色板（bg/surface/surface2/border/text/text2/accent/accentHover，浅深各一套）；补全之前漏掉的输入框、复选框、分组框、标签、链接的深色配色。
  - 给交互控件加圆角：输入框/下拉 9px、按钮 11px、分组框 12px、复选框 6px。
  - 启动按钮改为强调色实心填充；标题栏按钮改用主题色。
  - `InitPdone()` 末尾补 `UpdateStyle(_Setting.DarkMode)` 调用，确保初始启动即套用新样式（原仅切换深色开关时触发）。
- 风险：SunnyUI 个别属性名（Radius/FillColor/RectColor/TitleColor）若本地 VS 编译报错，按编译器提示微调即可，不影响功能。
